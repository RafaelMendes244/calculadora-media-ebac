## 📚 Sobre o Projeto

A **Calculadora de Média** é uma ferramenta online simples, rápida e gratuita, ideal para estudantes, professores e responsáveis que desejam calcular médias escolares com facilidade.

---

## 🚀 Funcionalidades

- ✅ Cálculo automático da média de notas
- ✅ Interface amigável e intuitiva
- ✅ Resultado instantâneo
- ✅ Responsivo para mobile e desktop
